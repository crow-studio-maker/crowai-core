# License selection required

The project owner has not selected a public license. Until a license is added, copyright law reserves all rights and outside reuse is not automatically granted.

Common Core choices:

- **Apache-2.0** — permissive, includes an explicit patent grant.
- **MIT** — short and permissive, with no explicit patent clause.
- **MPL-2.0** — file-level copyleft while allowing larger proprietary works.
- **AGPL-3.0** — strong copyleft including network use.

Model packages, weights, datasets, and private prompts may use different terms. The selected Core license should explicitly state that it covers only this repository unless another package says otherwise. Have qualified counsel review the final choice when commercial or third-party rights matter.
